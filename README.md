## 账号国家不是美国，卡买了能兑吗

不能。这是最容易被忽略、也最容易造成损失的一条。

Google 的规则是：礼品卡**只能在购买时所处的国家/地区，以相应币种兑换和使用**，账号的国家/地区设置必须与卡的发行地一致。换个说法，一张美区卡只能进美国区账号，兑成美元余额。

已经兑进去的余额，情况更死。官方明确写着，如果你更改了 Google Play 上的国家/地区，**已兑换的余额无法转移，只能在最初兑换时的国家/地区使用**。也就是说，你先把卡兑进美区账号，再把账号改成别的区，那笔钱就留在美区账号里，新区域用不上。

- **不能作为家庭支付方式**。家长想给未成年人买东西，得用家人群组绑定信用卡或借记卡，礼品卡不符合家庭支付方式的资格。
- **有年龄门槛**。使用者要符合所在区域服务条款规定的年龄要求。

对照自己账号现在的国家设置，是美国就买，不是美国就先处理账号，别先买卡。
